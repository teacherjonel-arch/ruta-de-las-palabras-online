# Ruta de las Palabras — Comunicación Online

Juego web multijugador para 2 a 4 jugadores.

- Cada jugador registra su propio nombre.
- El creador genera una sala con código.
- Los demás se unen con el código.
- El creador puede iniciar con 2, 3 o 4 jugadores.
- Turnos, posiciones, puntajes, preguntas y eventos se sincronizan mediante WebSocket.
- El juego original se conserva en `public/index.html`.

## Render
Build: `npm install`
Start: `npm start`
